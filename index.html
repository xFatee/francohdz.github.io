WORKATO · AWS EC2

Agente de IA para auditoría y gestión de seguridad en EC2

Agente construido en Workato que audita configuraciones de seguridad de instancias EC2 en AWS, corrige hallazgos automáticamente y crea nuevas instancias según políticas definidas — reduciendo intervención manual en tareas recurrentes de seguridad y aprovisionamiento.

WORKATO · AWS S3 · MCP · CLAUDE

Agente de corrección automática de buckets S3 expuestos

Agente que se conecta a AWS S3, detecta buckets con acceso público expuesto y los corrige automáticamente. El video muestra dos formas de ejecutarlo: primero como flujo nativo dentro de Workato, y después el mismo agente integrado por MCP (Model Context Protocol) a Claude, operando fuera de Workato con el mismo resultado.

WORKATO GENIE · POWER BI · MS TEAMS · DAX

Consulta conversacional de datos de Power BI con Agentes de Workato

Solución que permite consultar información de Power BI desde una app personalizada de Microsoft Teams usando lenguaje natural. Teams actúa como interfaz de conversación; Workato Genie interpreta la intención y selecciona una skill, que ejecuta una receta de Workato con la lógica de integración y validaciones. Workato se conecta al modelo semántico vía la Power BI REST API y ejecuta consultas DAX para obtener métricas, comparaciones o desgloses, y Genie devuelve la respuesta en lenguaje natural dentro de Teams.

Power BI sigue siendo la fuente de datos y visualización; Workato es la capa de integración y ejecución. El objetivo es reducir la navegación manual por dashboards para consultas recurrentes, con capacidades delimitadas por las skills configuradas en Workato.
